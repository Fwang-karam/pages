> 링크는 GitHub Pages가 켜져 있어야 열립니다. (Settings → Pages → Branch: `main` / `(root)`)

## 조작법

- **덤보 달리기**: `Space` 또는 `↑` 키로 점프, 모바일은 화면 터치
- **당근 피하기**: `←` `→` 키로 이동, 모바일은 화면 터치

## 참고

- DB Inc 실적 보고서의 수치는 실제 공시가 아닌 **예시(추정) 데이터**입니다.
- 모든 페이지는 단일 HTML 파일이며, 보고서 차트는 CDN의 Chart.js를 사용합니다.
